# order-scout

Сбор новых заказов с фриланс-бирж (FL.ru, Kwork) и отбор подходящих по нишам, стоп-словам, бюджету и числу откликов. Подходящие заказы сохраняются в SQLite и ждут оценки; у отсеянных записана причина.

> Проект в разработке: оценка заказов, подготовка откликов и Telegram-бот с карточками — следующий этап.

## Возможности

- FL.ru — RSS-лента, бюджет берётся из заголовка;
- Kwork — заказы из данных страницы биржи: желаемый и допустимый бюджет, число предложений;
- без дублей: повторно найденный заказ не сохраняется второй раз;
- если одна биржа недоступна, остальные собираются, ошибка выводится в отчёт;
- демо-режим с вымышленными заказами — без сети.

## Запуск

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
copy config.example.yaml config.yaml

# Демо: 8 вымышленных заказов, 4 проходят фильтр
.\.venv\Scripts\python -m order_scout collect --demo

# Настоящие биржи
.\.venv\Scripts\python -m order_scout collect
.\.venv\Scripts\python -m order_scout stats
```

База и лог лежат в `data/`.

## Настройки

Всё задаётся в `config.yaml` (пример с комментариями — `config.example.yaml`): источники, слова ниш, стоп-слова, минимальный бюджет, максимум откликов, интервал проверки (не чаще раза в 10 минут) и проекты портфолио.

## Тесты

```powershell
.\.venv\Scripts\pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest
```

Разбор лент проверяется на сохранённых образцах страниц (`tests/fixtures/`), сеть в тестах подменяется.

## Стек

Python 3.13, httpx, PyYAML, SQLite, pytest.
